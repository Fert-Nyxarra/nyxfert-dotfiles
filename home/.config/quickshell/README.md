# quickshell bar

A Wayland shell for Hyprland built with quickshell: one bar island, context
menus, a launcher, a wallpaper picker and a settings window. Colors come from
matugen and follow the current wallpaper.

## Requirements

* quickshell 0.3+, Hyprland 0.55+
* **JetBrainsMono Nerd Font** — every glyph in the bar comes from it
* matugen 4.2+ (older builds lack `--prefer`, which breaks automatic color
  extraction from images)
* PipeWire with WirePlumber, NetworkManager, swaybg, wl-clipboard
* optional: upower and power-profiles-daemon (battery), brightnessctl
  (backlight), grim/slurp/swappy/hyprshot (screenshots), wf-recorder

## Keys

| Keys | Action |
|------|--------|
| `Super` | application launcher |
| `Super + W` | wallpaper picker |
| `Super + V` | clipboard history |
| `Ctrl + Super + S` | settings |
| `Super + F` | fullscreen (hides the bar) |

## Modules

Left to right: launcher, workspaces, now playing, clock with calendar, tray,
volume, network, battery, keyboard layout, notifications. Left click acts,
right click opens the module menu, the wheel adjusts where it makes sense.

Workspaces show five dots out of ten: the set follows the group you are in,
so moving to the sixth desktop swaps the dots to 6–10.

## Settings

`Ctrl + Super + S` opens a tabbed window.

* **Bar** — position (top, bottom, left, right) and style: *island* (rounded,
  with margins) or *panel* (flush to the edge, square corners).
* **Windows** — layout (tiling or scrolling), border width, corner rounding
  and window animation. These are Hyprland settings; the shell hands them
  over with `hyprctl eval` and re-applies them after every config reload, so
  `hyprland.lua` stays untouched.

Choices live in `~/.local/state/quickshell/settings.json`, outside the config
directory: matugen rewrites `Colors.qml`, which makes quickshell reload and
would reset anything kept in memory.

## Layout

```
shell.qml             entry point, one bar per monitor
Theme.qml             sizes, fonts, geometry derived from Settings
Colors.qml            generated by matugen, do not edit by hand
Settings.qml          user settings, stored outside the config
bar/                  modules and their menus
widgets/              shared pieces: bar items, menus, sliders, hue wheel
```

## Editing

quickshell reloads on save; errors show up in `qs log`. Sizes and fonts are
in `Theme.qml`, module order in `bar/Bar.qml`, colors in the matugen template
at `~/.config/matugen/templates/quickshell-colors.qml`.

Material You roles are renamed in the template: `on_primary` becomes
`textOnPrimary`, `on_surface` becomes `text`, `on_surface_variant` becomes
`subtext` — QML treats a property starting with `on` plus a capital letter as
a signal handler.

## Moving to another machine

`~/bin/export-setup` packs the configs, wallpapers and installers into an
archive. On the target machine run `./install.sh` (NixOS) or
`./install-arch.sh` (Arch). Only what the shell itself needs gets installed —
no browsers, messengers or media players.
